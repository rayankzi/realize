02

The scheduled automation task

The seven steps the recurring Claude automation runs end to end. Click any step to expand it.

Links only

Read links from notion_pages.json. Ignore page_ids entirely during analysis.

Launch in parallel

When batching, fire all subagents at once via the Task tool — never one at a time.

Always close out

Run organize-output only after every URL finishes; always run cleanup last, even on failure.

Hands off the source

Don’t modify source files, debug scripts, or touch the venv. Record errors and move on.

.claude/ configuration

Project-scoped Claude Code config. One file plus the skills library.

.claude/settings.local.json
permission allowlist

A single permissions.allow array — no hooks, no env, no secrets. It pre-approves exactly the commands the automation needs so it can run unattended.

Allows shell tools (python3, ls, find, cat, source venv, ffmpeg, brew, npm/npx, tree), the claude -p "/organize-output" skill invocation, WebSearch, and scoped Read paths (Homebrew, npm, claude local, task tmp dirs).

06

Primary workflows

Two ways the system runs: the unattended batch automation, and a single ad-hoc analysis.

A · Scheduled batch automation

recurring · unattended
  1. Activate the venv (and all subagents do too).
  2. Run fetch_notion_pages.py → notion_pages.json.
  3. Read links; stop if empty.
  4. <6 URLs → sequential; ≥6 → up to 6 parallel subagents, each running run_analysis.py per URL.
  5. Invoke /organize-output via headless Claude CLI.
  6. Run cleanup.py — mark pages Done, wipe temp.
  7. Emit a success/failure summary report.

B · Single ad-hoc run

manual · one URL
  1. python3 backend/run_analysis.py <instagram_url>
  2. get_instagram_graphql_data() fetches metadata + media.
  3. Has a video_url? → reel path: download → transcribe → (decide → extract → filter frames) → /analyze-video.
  4. No video? → carousel path: download images + caption → /analyze-post.
  5. Markdown summary lands in output/; run /organize-output + cleanup.py to file & close it.
