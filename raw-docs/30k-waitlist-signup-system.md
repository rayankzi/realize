# The 7-Day Persona Experiment: A Blueprint for 30K+ Waitlist Signups

**Topic/Category:** Startup Growth / Marketing Strategy
**Primary Goal of the Reel:** To teach founders a structured system for generating waitlist signups by testing multiple customer personas using short-form video and tailored landing pages.

---

## Executive Summary

The video outlines a "secret system" used to acquire over 30,000 waitlist signups. The strategy involves identifying seven distinct customer personas, creating seven targeted short-form videos (one per persona), and building seven unique landing pages using Claude Code. By running this experiment over seven days on platforms like Instagram or TikTok, founders can identify which audience segment converts best and double down on that niche.

## Core Insights & Takeaways

- **Platform Selection:** Instagram is preferred for tech and software niches, while TikTok is better for consumer-facing apps or products.
- **Persona-Driven Marketing:** Instead of a generic approach, target seven specific user types to find the "winning" audience segment.
- **Automation is Key:** Use tools like ManyChat or Inro to automate DM responses triggered by specific keywords in the comments, ensuring immediate lead delivery to the correct landing page.
- **Rapid Iteration:** A 7-day test period is sufficient to identify patterns in user engagement and conversion, allowing for data-driven decisions on which niche to scale.
- **Leveraging AI Tools:** Use Claude Code to rapidly spin up multiple tailored waitlist pages, reducing the technical friction of creating personalized landing pages for each persona.

## Narrative & Step-by-Step Breakdown

1. **Pick a Platform:** Decide between Instagram (for tech/B2B) and TikTok (for consumer/B2C) based on your product niche.
2. **Identify 7 Personas:** Define seven different types of people who would benefit from and buy your product.
3. **Script 7 Videos:** Create one video script for each of the seven personas. Use proven viral formats within your specific niche to increase reach.
4. **Create 7 Tailored Landing Pages:** Use Claude Code to build a specific waitlist page for each persona, ensuring the headline and benefits are tailored to that specific user type.
5. **Implement CTA & Automation:** Each video must end with a Call to Action (CTA) asking viewers to comment a "trigger word." Set up automation (e.g., ManyChat) to automatically DM the link to the corresponding persona-specific landing page.
6. **Post Daily for 7 Days:** Execute the sprint by posting one targeted video each day for a full week.
7. **Analyze Results:** Observe which video/persona/page combination generated the most engagement and signups. Double down on the winning segment.
