## Executive Summary

The creator demonstrates a 3-step workflow for building visually polished websites using Claude Code. By combining two MCP servers (ShadCN and Magico), a frontend design skill plugin, and Playwright-based screenshot feedback, Claude Code gains the capabilities of a senior UI/UX designer and can iteratively self-improve the output. ## Core Insights & Takeaways

- **MCP Servers unlock pre-built components:** Installing ShadCN and Magico MCP servers gives Claude Code access to thousands of ready-made UI components, dramatically raising the baseline quality of generated interfaces.
- **The frontend-design plugin adds design judgment:** Running `/plugins` and installing the frontend-design plugin equips Claude with senior UI/UX design skills on every subsequent prompt — no extra instruction needed.
- **Playwright enables visual self-improvement:** Giving Claude access to Playwright allows it to screenshot the live site and iterate on its own output, closing the feedback loop without human intervention.
- **The full workflow is three discrete steps:** Install MCP servers → install the design plugin → connect Playwright. Each step builds on the last.

## Narrative & Step-by-Step Breakdown

1. **Install MCP servers** — Add ShadCN and Magico MCP servers to Claude Code. These servers provide access to thousands of pre-built UI components that Claude can pull from during generation.
2. **Install the frontend-design plugin** — Run `/plugins` inside Claude Code and install the frontend-design plugin. Once installed, Claude Code inherits the reasoning and aesthetic instincts of a senior UI/UX designer for all future requests.
3. **Connect Playwright for iterative screenshots** — Give Claude Code access to Playwright so it can screenshot the rendered website, evaluate the result visually, and make improvements automatically — a self-reinforcing design loop.
