# Automating Rough Cut Video Edits with Claude Code & Remotion

**Topic/Category:** AI Video Editing / Workflow Automation
**Primary Goal of the Reel:** To demonstrate how to leverage Claude Code, Remotion, and Whisper to automate the "rough cut" phase of video editing, significantly reducing time and costs associated with manual editors.

---

## Executive Summary

This reel introduces a high-efficiency workflow that transforms Claude Code into an automated video editor. By integrating Remotion for programmatic video manipulation and Whisper for precise transcription-based cutting, users can automatically remove "dead space" from footage. The creator claims this setup takes only 20 minutes to configure and can save up to $4,000 per month on professional editing services by streamlining the initial rough cut process before final polishing in software like Adobe Premiere Pro.

## Core Insights & Takeaways

- **Workflow Synergy:** Combining Claude Code (CLI) with Remotion (programmatic video) and Whisper (transcription) creates a powerful automated editing pipeline.
- **Cost & Time Efficiency:** Replaces the need for a human editor for the initial rough cut, reportedly saving $4k/month.
- **Seamless Integration:** The rough cuts generated can be imported directly into professional software like Premiere Pro for final adjustments.
- **Dead Space Removal:** The primary technical benefit is the automated removal of silence and pauses from raw footage.
- **Custom Skill Creation:** Users can create a custom "Rough Cut" skill within Claude Code to reuse this workflow easily.

## Narrative & Step-by-Step Breakdown

1. **Visit Remotion:** Navigate to `remotion.dev` to access the necessary boilerplate or installation code.
2. **Initial Setup:** Copy the installation code from Remotion and paste it into the Claude Code terminal.
3. **Configure Pipeline:** Instruct Claude Code to install Remotion and Whisper, specifically for transcribing clips to generate rough cuts.
4. **Create Custom Skill:** Within Claude Code, create a reusable skill (e.g., named "Rough Cut") to handle the editing logic.
5. **Process Footage:** Point the skill to a video file (e.g., `test.mov` on the desktop).
6. **Execute Edit:** Use the "Whisper precise version" to analyze the audio and "crunch" the video.
7. **Verification:** Claude Code outputs the edited file with all dead space removed, ready for professional import.
