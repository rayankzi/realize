## Detailed Breakdown / Step-by-Step

**Project 1: Cloud-Based Active Directory Setup and User Management**
- **Technical skills:** Cloud IAM, RBAC design, directory services, access provisioning
- **Add to resume:** Implementing identity lifecycle management, least-privilege access models, and secure cloud authentication flows
- **Jobs:** Cloud Security Analyst, IAM Engineer
- **Typical pay:** ~$75K–$190K

**Project 2: Cloud Security Risk Assessment & GRC Simulation (Azure)**
- **Technical skills:** Risk modeling, control mapping, compliance analysis, cloud governance
- **Add to resume:** Evaluating security controls, identifying exposure gaps, and translating risk into actionable remediation plans
- **Jobs:** GRC Analyst, Security Risk Analyst
- **Typical pay:** ~$80K–$160K

**Project 3: Linux Log File Analysis, Automation, and SIEM Visualization**
- **Technical skills:** Log parsing, event correlation, scripting automation, SIEM workflows
- **Add to resume:** Detecting anomalous behavior, building detection logic, and operationalizing security telemetry
- **Jobs:** SOC Analyst, SIEM Engineer, Threat Analyst
- **Typical pay:** ~$70K–$170K

**Project 4: Network Scanning and Host Enumeration with Nmap**
- **Technical skills:** Network reconnaissance, service enumeration, vulnerability identification
- **Add to resume:** Mapping attack surfaces, validating exposure, and interpreting scan data for security assessment
- **Jobs:** Penetration Tester, Vulnerability Analyst
- **Typical pay:** ~$90K–$170K

**Project 5: Web Application Scanning with OWASP ZAP (AppSec Project)**
- **Technical skills:** Web vulnerability testing, attack surface analysis, remediation validation
- **Add to resume:** Identifying application-layer weaknesses and prioritizing exploit risk
- **Jobs:** Application Security Engineer, Web Pentester
- **Typical pay:** ~$105K–$200K
