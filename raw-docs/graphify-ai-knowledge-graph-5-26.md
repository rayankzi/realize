# Graphify: Turning Any Folder into an AI Knowledge Graph

**Topic/Category:** DevTools, AI Coding, Open Source
**Primary Goal of the Reel:** To introduce "Graphify," a tool inspired by Andre Karpathy that automatically builds a queryable knowledge graph from local files (code, notes, research).

---

## Executive Summary

The reel highlights the rapid development of "Graphify," a tool created in just 48 hours following a public request from Andre Karpathy. It addresses the common pain point of navigating scattered folders and high token costs by converting any directory into an interactive knowledge graph. By integrating with tools like Obsidian and offering plain-English querying, Graphify aims to revolutionize how developers and researchers interact with their local data.

## Core Insights & Takeaways

- **Rapid Innovation:** The tool was built and released within 48 hours of Andre Karpathy suggesting its necessity.
- **Knowledge Transformation:** Graphify takes a folder of code, notes, or PDFs and transforms it into a structured knowledge graph.
- **Efficiency:** Claims to use 71.5x fewer tokens per query compared to traditional methods by mapping connections between files.
- **Accessibility:** It is open-source, free, and requires zero setup.
- **Integration:** Outputs include an Obsidian vault, an interactive wiki, and the ability to ask natural language questions about the codebase (e.g., "What calls this function?").
