# Graphify: Turning Your Folders into an AI-Powered Knowledge Graph

**Topic/Category:** Developer Tools / AI Software Engineering
**Primary Goal of the Reel:** To introduce "Graphify," an open-source tool that automatically converts folders (code, notes, research) into a full knowledge graph, and highlight how quickly it was built following a request from Andrej Karpathy.

## Executive Summary

Graphify is a revolutionary open-source tool built in just 48 hours after Andrej Karpathy expressed a need for such a system. It allows users to point a single command at any local folder—containing code, PDFs, images, or research—and automatically maps every file and connection into a structured knowledge graph. This system dramatically improves codebase exploration and research efficiency by providing interactive wikis, Obsidian vault integration, and 71.5x fewer tokens per query compared to traditional methods.

## Core Insights & Takeaways

- **Automated Mapping:** One command can map an entire folder of diverse files (code, notes, research) into a full knowledge graph.
- **Extreme Efficiency:** Claims a 71.5x reduction in token usage per query compared to scattered folder exploration.
- **Versatile Output:** Generates an Obsidian vault and an interactive wiki for exploring connections.
- **Natural Language Queries:** Enables plain-English questions about the codebase, such as "What calls this function?"
- **Rapid Development:** The tool was developed and released on GitHub within 48 hours of Andrej Karpathy posting his LLM knowledge base workflow.
