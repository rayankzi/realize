# Graphify: Turning Your Folders into an AI Knowledge Graph

**Topic/Category:** AI Dev Tools / Knowledge Management
**Primary Goal of the Reel:** To introduce "Graphify," an open-source tool that automatically converts folders (code, notes, research) into a queryable knowledge graph, and to highlight its speed of development (built in 48 hours following a request by Andrej Karpathy).

---

## Executive Summary

Graphify is a new open-source tool inspired by Andrej Karpathy's workflow for managing LLM knowledge bases. It allows users to point a single command at any local folder to generate a full knowledge graph, including an Obsidian vault and an interactive wiki. By mapping connections between files—whether they are code, PDFs, or images—it significantly reduces token usage (71.5x fewer tokens per query) while enabling natural language questions like "What calls this function?".

- **Efficiency:** Claims a 71.5x reduction in tokens per query compared to traditional methods.
- **Output Formats:** Generates an Obsidian vault and an interactive wiki for visualization and exploration.
