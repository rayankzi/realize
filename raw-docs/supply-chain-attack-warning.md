# Are Your Dependencies Hacked? Supply Chain Attack Warning for Developers

**Topic/Category:** Cybersecurity / Secure Coding

## Executive Summary

Security engineer Jasmine (@cyberjasbytes) sounds the alarm on a growing wave of supply chain attacks where attackers are pushing malicious versions of widely-used packages like LiteLLM, Axios, and Trivy — packages embedded in virtually every modern application. These compromised dependencies can steal API keys and credentials. Jasmine points developers to a detailed Substack article she wrote covering how to check if you're impacted, how to remediate, and how to prevent future exposure.

## Core Insights & Takeaways

- **Supply chain attacks are actively happening now:** Real dependencies (LiteLLM, Axios, Trivy) have been compromised with malware designed to steal credentials and API keys.
- **Everyone who writes code is at risk:** Whether you're a professional developer or someone "vibe coding" with AI tools, you are calling third-party dependencies and are potentially exposed.
- **Don't just check direct dependencies:** Transitive (indirect) dependencies are equally dangerous and often overlooked. Attackers exploit this blind spot.
- **Organizations are actively firefighting this:** This isn't theoretical — companies are currently dealing with incidents related to these compromised packages.
- **A Substack guide exists for action:** Jasmine has written a full step-by-step article covering detection, remediation, and preventative techniques — accessible by commenting "link" on the post.
