# Mira Murati's "Thinking Machines": The End of Turn-Based AI

**Topic/Category:** AI Research, Tech News, Future of Human-AI Interaction

## Executive Summary

Mira Murati's new venture, Thinking Machines Lab, has unveiled a research preview of "Interaction Models"—a breakthrough in AI architecture designed to eliminate the "turn-based" nature of current models. Unlike systems that wait for a user to finish speaking before processing, these models operate in 200ms chunks, allowing them to listen, see, and speak simultaneously. This "full duplex" capability enables real-time collaboration, lower latency, and proactive visual understanding that surpasses current state-of-the-art models like GPT-4o.

## Core Insights & Takeaways

- **Eliminating the Processing Gap:** Current AI models (voice and agents) are turn-based, leading to a "collaboration bottleneck" where the model is blind/deaf while processing or generating.
- **Continuous Perception:** Interaction Models process data in 200-millisecond slices, enabling continuous input and output in the same loop.
- **Dual Model Architecture:** The system uses a "live interaction model" for real-time conversation and a "background model" for deep thinking, web searching, and tool calling.
- **Human-Level Latency:** Thinking Machines achieved a turn-taking latency of 0.40 seconds, matching natural human conversation speed and significantly beating GPT-4o's 1.18 seconds.
- **Visual Proactivity:** The model can perform tasks requiring constant visual monitoring, such as counting push-up reps or answering questions as soon as they appear on screen—tasks most current models fail at.
