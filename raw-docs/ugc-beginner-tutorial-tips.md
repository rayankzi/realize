## Core Insights & Takeaways

- **UGC Definition:** User Generated Content is when you create promotional videos using a product as an organic user and send it to the company.
- **No Followers Needed:** Unlike traditional influencing, UGC doesn't require a large social media following because the content is for the brand's use, not yours.
- **The Portfolio Challenge:** Building a portfolio ("folio") is the hardest part for beginners with no clients.
- **Resource Recommendation:** Linda Lin's tutorial provides a step-by-step guide to building a portfolio without followers, including suggested fees and communication walkthroughs.
- **Community Invitation:** The creator is documenting her own journey from zero to $10k/month in 2 months, inviting others in the same position to follow along.
